# Type 5 — Assessment Report: user guide

## 1. Create the order
New Order → **5 · Assessment Report** → fill in the client and property as for any order → tick the fees → Submit. A new Type 5 starts in DRAFT, like every new order. There is no valuation for this type; the Valuation buttons say so.

## 2. Record the assessment
Inspect Data → **Assessment** tab. Everything saves as you type, however incomplete. The list at the top shows what is still needed; click an item to jump to it.

1. **Assignment** — purpose, intended use, recipients, inspector, reviewer, and the dates. Inspection, effective and issue dates are kept separate.
2. **Scope, method and access**
   - Choose the method: visual, limited visual, desktop review or specialist-assisted.
   - Choose the access: full, partial, exterior only, none or document-only.
   - For a **desktop review**, list the documents. The report will say the property was not visited.
   - Give every area its source. Only "Measured on site" prints as a measurement.
3. **Locations** (optional) — one per building, unit, floor or room.
4. **Condition matrix** — for each of the ten components, say whether it applies and whether it was inspected. A condition can only be given for something inspected. If it was not inspected, say why.
5. **Findings** — **+ Finding** gives the next reference (F-001, F-002…).
   - Record the observation, location, priority and recommended action, or choose Monitor and explain the decision.
   - Keep a *suspected* cause apart from a *confirmed* one; a confirmed cause needs its source.
   - Attach evidence from the order's own photos (Inspect Data › Photos) and add a caption.
   - An **urgent** finding needs evidence or a reason there is none. The reviewer acknowledges that reason before issuing.
   - Removing a finding keeps its reference reserved.
6. **Costs** (optional) — tick to include the schedule.
   - Each line is **either** quantity × (materials + labour) **or** a lump sum.
   - Leave a price blank if it is not estimated: the total then prints as INCOMPLETE.
   - Untick *Included* to keep a line on record without counting it.
   - Contingency and tax apply only if you enter them.
   - A line in the other currency needs the exchange rate, its date and its source.
7. **Professional assessment** — overall condition and why. Add the executive summary and limitations.
8. **Copy observations** (appears when another Type 5 has findings) — copies findings only. Each is marked for confirmation.

## 3. Review and issue
Bottom of the Assessment tab:
- **Submit for review** — possible only when nothing on the list blocks it.
- The reviewer writes the **reviewer conclusion**, then **Approve this revision**. Changing anything afterwards cancels the approval, and it must be approved again.
- Name the **signatory**, then **Issue revision N**. The content is now fixed.
- To correct an issued report, give a reason and **Open revision N+1**. The issued revision stays exactly as it was.

## 4. The report
**Report** builds the Assessment Report:
- Until a revision is issued, every page carries the **DRAFT** watermark and the signature line reads "not signed".
- Once issued, the report prints that revision's frozen content.
- Releasing it to the client still uses the **DRAFT** switch on Quick-View, which needs the invoice paid.
- When an issued revision is published with DRAFT off, its PDF is also kept under its own name. The Review panel links to it.

The pre-flight check before generating shows: the revision state, anything blocking issue, missing evidence photographs, and whether the cost schedule is complete.
